# Renaker Life Case Study

Cinematic interactive case study for Renaker Life, powered by Aiyla.

## Develop

```bash
nvm use 20
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

Debug 3D anchors/camera: [http://localhost:3000?debug3d=1](http://localhost:3000?debug3d=1)

## Stack

- Next.js App Router + TypeScript
- React Three Fiber / Three.js / drei
- GSAP ScrollTrigger
- Tailwind CSS v4
- Aiyla design tokens (Manrope, stone/ink, glass)
